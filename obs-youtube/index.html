OBS YouTube 配信補助

OBS Studio から YouTube へ配信する際の定型作業を自動化する、個人用の OBS スクリプトです。作者本人の YouTube チャンネルでのみ使用しています。

機能

  • 配信開始時に、配信タイトルを「日付 + ゲーム名」の形式に変更
  • 配信を指定の再生リストへ追加（追加済みの場合は省略）
  • 配信の公開範囲を確認し、限定公開以外の場合は限定公開へ変更
  • OBS のドックからゲーム名の入力と配信の開始・終了を操作

Google アカウントの利用

上記の操作のため、YouTube Data API を通じて、作者の YouTube チャンネルへのアクセス権限（https://www.googleapis.com/auth/youtube）を使用します。取得するのは、配信中のライブ配信、動画のタイトル、再生リスト、チャンネル名の情報です。

取得した情報と認証情報は、スクリプトを実行している PC の中だけで扱い、作者を含む外部のサーバーへは送信しません。詳細はプライバシーポリシーに記載しています。
