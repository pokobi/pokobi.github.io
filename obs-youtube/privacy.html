プライバシーポリシー

制定日：2026年11月7日

このポリシーは、OBS スクリプト「OBS YouTube 配信補助」（以下「本スクリプト」）における情報の取り扱いを定めるものです。

1. 利用する情報

本スクリプトは、YouTube API サービスを通じて次の情報を利用します。

  • 認証したチャンネルの ID と名前
  • 配信中のライブ配信の ID、タイトル、説明、カテゴリ、タグ、公開範囲
  • 再生リストの ID、名前、公開範囲、所有チャンネル、登録されている動画

2. 利用目的

取得した情報は、配信タイトルの変更、再生リストへの動画の追加、公開範囲の確認と変更のためにのみ使用します。広告、分析、その他の目的には使用しません。

3. 保存と送信

Google の認証情報（リフレッシュトークン）は、スクリプトを実行している PC 内のファイル（token.json）にのみ保存します。上記の情報は Google のサーバー（YouTube API）との通信にのみ使用し、作者を含む第三者のサーバーへは送信・共有しません。動作ログは OBS 内に表示するのみで、外部へは送信しません。

4. アクセス権の取り消しと削除

本スクリプトへのアクセス権は、Google アカウントのサードパーティ アクセス設定からいつでも取り消せます。PC 内に保存された情報は、token.json を削除することで消去できます。

5. YouTube API サービスと Google のポリシー

本スクリプトは YouTube API サービスを使用しています。YouTube API サービスを通じて取得される情報は、Google プライバシーポリシーに従って取り扱われます。

6. 改定

このポリシーを改定した場合は、このページを更新し、制定日の欄に改定日を記載します。
